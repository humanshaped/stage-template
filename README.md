# My talk

This repository is one talk you give with the Human Shaped add-on for Google Meet. It belongs to you, and everything in it is public.

- `talk.md` is your talk, written as text. Each `---` starts a new slide, and a line starting with `>` is a note only you see.
- `index.html` is the page you can show on the main stage, where everyone in the call gets their own working copy.
- `AGENTS.md` tells an AI agent how to help you change either one.

Learn more about building this way at [humanshaped.org](https://humanshaped.org).
