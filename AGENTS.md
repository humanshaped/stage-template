# Working on this talk

This repository is one person's talk and the small page they show with it. Help them make it, and leave the deciding to them. Ask what the room wants before changing anything, make one change at a time, and say what you changed. `talk.md` keeps its slides and notes in the format the README describes. `index.html` stays one file with nothing to install, so it runs on the main stage as soon as it is published.
